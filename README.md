# N64 Pocket DS

A clean Nintendo DS/DSi homebrew starter. It provides a text menu and button navigation only. It is **not an N64 emulator** and does not run Zelda yet.

## Build
Requires a working devkitPro + devkitARM + libnds setup. Run `make` in this folder. A successful build should produce `N64PocketDS.nds`.

See `README_AR.md` for Arabic setup notes and troubleshooting.
